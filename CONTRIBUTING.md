# Contributing to flea-CachyOS

Thanks for helping. This fork is where improvements to Flea on CachyOS, Hyprland and Noctalia live, so please open your pull requests here.

- **Fixes and features for this setup** (Noctalia colours, Hyprland bindings, the CachyOS package, the replaced `Commons` and `Ui` libraries): pull request to this fork.
- **Changes that help every Flea user**: we will also consider offering them upstream to `thisisgm/flea`.
- **License**: this fork is GPL-3.0. Any contribution you send is accepted under the same license (see [NOTICE.md](NOTICE.md)).
- **Keep upstream changes small**: edits to upstream files should stay minimal and isolated, so upstream releases can be merged without pain. See [docs/cachyos/sync-upstream.md](docs/cachyos/sync-upstream.md).
- **Language**: code, comments, commit messages and issues in English.
